GPS-fused 3D mapping for the Voltrac Tierra

A TSDF 3D mapping pipeline for an outdoor autonomous ground robot, built as a take-home task for Voltrac in Spain. It turns raw multi-camera sensor data into a dense triangle mesh with a GPS-corrected trajectory overlay.

  • EKF GPS fusion: wheel encoders and IMU gyroscope for prediction, RTK-grade GPS position and heading for update, in a local ENU frame with an SE(3) pose per frame
  • TSDF integration of depth frames with Open3D ScalableTSDFVolume (5 cm voxels, 20 cm truncation, 8 m depth limit)
  • Mesh extraction with marching cubes, exported as OBJ and PLY
  • Input: raw MCAP data from six 1920x1200 RGB cameras, a depth camera, an IMU and RTK GNSS
  • EKF
  • TSDF
  • Open3D
  • SE(3)
  • RTK GNSS
  • MCAP

Error-state filter on SO(3), the core idea 
Propagate (IMU, high rate)    Rk+1 = Rk · Exp( (ωk − bg) Δt )
Visual update (camera rate)   correct the error state δφ in so(3)
Inject back onto the manifold R ← R · Exp(δφ)
